# Kafka Path 0.3.3 — локальный запуск

## Требования

- Node.js 22.13 или новее: https://nodejs.org/
- Windows 10/11, Linux или macOS

## Запуск в Windows

Откройте `cmd` или PowerShell в папке проекта:

```cmd
npm install
npm run dev
```

Откройте адрес из терминала — обычно `http://localhost:5173`.
Остановка сервера: `Ctrl+C`.

После первого запуска обычно достаточно только `npm run dev`.

## Открытие с другого устройства в домашней сети

```cmd
npm run dev -- --host
```

Vite покажет адрес вида `http://192.168.x.x:5173`. Оба устройства должны быть
в одной сети. Windows Firewall может запросить разрешение для Node.js.

Если порт занят:

```cmd
npm run dev -- --port 5174
```

Предупреждения `npm warn deprecated` не мешают запуску, если установка завершилась
успешно. Реальный Kafka-кластер для симулятора не нужен.
